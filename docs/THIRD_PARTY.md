# Third Party Dependencies

## Backend
- **Spring Boot (3.3.4)**: Application framework and embedded Tomcat server. (Apache 2.0)
- **Spring Security & jjwt**: Authentication and authorization. (Apache 2.0)
- **H2 Database**: In-memory relational database. (MPL 2.0 / EPL 1.0)
- **Apache PDFBox (2.0.29)**: PDF text extraction tool. (Apache 2.0)
- **OpenAI API**: External LLM and Embeddings provider. (Commercial SaaS)

## Frontend
- **React 19 & React DOM**: UI Library. (MIT)
- **Vite**: Build tool and dev server. (MIT)
- **Tailwind CSS v4**: Utility-first CSS framework. (MIT)
- **Lucide React**: Icon library. (ISC)
- **Axios**: HTTP client. (MIT)
- **React Router DOM**: Client-side routing. (MIT)
